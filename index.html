                        Architecture
                        
What is the role of dispatcher servlet?

                        
 Tap to flip

                      

                      

                        
The DispatcherServlet

                        
It is the core **Front Controller** in Spring MVC. It intercepts every incoming HTTP request and acts as a traffic officer, coordinating controllers, URL mappings, and resolvers to find and execute the correct endpoint.

                      

                    

                  


                  
                  

                    

                      

                        Security
                        
Why are REST APIs stateless?

                        
 Tap to flip

                      

                      

                        
Stateless REST APIs

                        
Stateless means the server **never stores browser sessions**. Every request contains all necessary credentials (like JWT inside header). This allows the application to easily scale across millions of servers without session syncing lag.

                      

                    

                  


                  
                  

                    

                      

                        Performance
                        
Explain Lazy Loading vs Eager Loading?

                        
 Tap to flip

                      

                      

                        
Hibernate Loading

                        
**Eager Loading** retrieves a record AND all related records instantly in one massive query. **Lazy Loading** delays fetching child data until your Java code explicitly calls it, boosting database efficiency.
